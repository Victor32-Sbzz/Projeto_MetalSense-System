# Projeto_MetalSense-System
MetalSense é um sistema inteligente desenvolvido pela equipe TechForge para monitorar máquinas do setor de corte e dobra da indústria metalúrgica. O sistema analisa dados como temperatura, vibração e consumo elétrico, identificando alterações no comportamento das máquinas que possam indicar possíveis falhas ou necessidade de manutenção preventiva.
